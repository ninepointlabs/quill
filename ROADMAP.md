# Quill Roadmap

## Done

- [x] Feed with three tabs (Following, Replies, My Notes)
- [x] Profile resolution with avatars (Coil disk cache)
- [x] Omostrich remote signing over Tailscale
- [x] nostrdb native layer (ARM64 + x86_64)
- [x] Thread view with reply context
- [x] Blossom media support (images + video thumbnails)
- [x] Link previews (Open Graph)
- [x] Tappable nostr: links (njump.me)
- [x] Cold start disk caching (nostrdb + profiles.json + Coil)
- [x] Compose + post flow
- [x] Omarchy design language

## Near term

- [ ] NWC (Nostr Wallet Connect) zaps
- [ ] Reactions (like/repost) via Omostrich signing
- [ ] Follow/unfollow via Omostrich signing
- [ ] DM support (NIP-04/NIP-44 encrypted)
- [ ] Push notifications via relay subscriptions
- [ ] Profile screen (tap author name/avatar)
- [ ] Image viewer fullscreen
